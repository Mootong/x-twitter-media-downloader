# 安全说明

## 权限

- `activeTab`、`tabs`：定位并导航当前 X 标签页。
- `downloads`：保存图片和完整 MP4。
- `storage`：保存设置、扫描结果和进度。
- `x.com`、`twitter.com`：扫描用户有权访问的推文。
- `pbs.twimg.com`、`video.twimg.com`：下载媒体。
- `127.0.0.1:17863`：向本地 HLS/DASH 辅助服务提交任务。

## 本地辅助服务

- 仅绑定 `127.0.0.1`，不接受局域网连接。
- 写入路径限制在当前用户的 `Downloads` 目录下。
- 输入媒体限制为 X 的 HTTPS 媒体域名。
- 修改状态的请求要求 `Origin` 为 `chrome-extension://`。

本地其他恶意扩展仍可能访问回环服务。正式分发前建议增加一次性配对密钥，
并由扩展和辅助程序共同保存。

## 数据

扫描结果只保存在扩展本地存储，不上传到项目控制的服务器。X 本身仍会收到
正常浏览和媒体请求。
