# Chrome Web Store 本地化文案

以下文案用于商店后台的本地化 Store Listing。隐私政策、支持网址和权限披露在
所有语言中使用相同链接。

## English (`en`)

**Name:** Media Downloader for X

**Summary:** Scan media posts on X by username and date, preview the results,
and download selected images and videos.

**Description:**

Media Downloader for X is an unofficial extension for organizing and
downloading X media that you own or are authorized to save.

- Scan a user's media page by date and maximum post count.
- Find every image in multi-image posts.
- Select the best available MP4 video variant.
- Preview results and choose individual items before downloading.
- Save files in a Downloads subfolder named after the username.
- Export scan reports as CSV or JSON.
- Store settings and recent usernames locally.

Images, MP4 files, and scanning require no external service. HLS/DASH merging is
optional and requires the open-source localhost helper and a separate permission
prompt. No scan data is uploaded to a developer server. No ads or analytics are
included.

Only download content you own or are authorized to save. This extension is not
affiliated with or endorsed by X Corp.

## 日本語 (`ja`)

**名前：** X メディアダウンローダー

**概要：** ユーザー名と日付で X のメディア投稿をスキャンし、結果を確認して
選択した画像や動画をダウンロードします。

**説明：**

X メディアダウンローダーは、所有または保存許可のある X のメディアを整理・
ダウンロードするための非公式拡張機能です。

- 日付と最大投稿数を指定してユーザーのメディアページをスキャン。
- 複数画像の投稿からすべての画像を取得。
- 利用可能な最高品質の MP4 動画を選択。
- プレビューページで項目ごとに選択してダウンロード。
- ユーザー名の付いたダウンロードサブフォルダーに保存。
- CSV または JSON のスキャンレポートを出力。
- 設定と最近のユーザー名をローカルに保存。

スキャン、画像、MP4 のダウンロードに外部サービスは不要です。HLS/DASH の
結合は任意機能で、オープンソースの localhost ヘルパーと個別の権限が必要です。
スキャンデータは開発者のサーバーへ送信されず、広告や分析も含まれません。

所有または保存許可のあるコンテンツのみダウンロードしてください。本拡張機能
は X Corp. と提携しておらず、同社の承認も受けていません。

## 한국어 (`ko`)

**이름:** X 미디어 다운로더

**요약:** 사용자 이름과 날짜로 X 미디어 게시물을 스캔하고 결과를 미리 본 뒤
선택한 이미지와 동영상을 다운로드합니다.

**설명:**

X 미디어 다운로더는 사용자가 소유하거나 저장 권한이 있는 X 미디어를 정리하고
다운로드하기 위한 비공식 확장 프로그램입니다.

- 날짜와 최대 게시물 수로 사용자 미디어 페이지 스캔.
- 여러 이미지가 포함된 게시물에서 모든 이미지 찾기.
- 사용 가능한 최고 품질의 MP4 동영상 선택.
- 미리보기 페이지에서 항목별로 선택 후 다운로드.
- 사용자 이름으로 된 다운로드 하위 폴더에 저장.
- CSV 또는 JSON 스캔 보고서 내보내기.
- 설정과 최근 사용자 이름을 로컬에 저장.

스캔, 이미지 및 MP4 다운로드에는 외부 서비스가 필요하지 않습니다. HLS/DASH
병합은 선택 기능이며 오픈 소스 localhost 도우미와 별도 권한이 필요합니다. 스캔
데이터는 개발자 서버로 업로드되지 않으며 광고나 분석 기능이 없습니다.

소유하거나 저장 권한이 있는 콘텐츠만 다운로드하세요. 이 확장 프로그램은
X Corp.와 제휴하거나 승인을 받지 않았습니다.

## Español (`es`)

**Nombre:** Descargador multimedia para X

**Resumen:** Escanea publicaciones multimedia de X por usuario y fecha,
previsualiza los resultados y descarga imágenes y vídeos seleccionados.

**Descripción:**

Descargador multimedia para X es una extensión no oficial para organizar y
descargar contenido de X que te pertenece o que tienes permiso para guardar.

- Escanea la página multimedia de un usuario por fecha y cantidad máxima.
- Encuentra todas las imágenes de publicaciones con varias imágenes.
- Selecciona la mejor variante MP4 disponible.
- Permite elegir elementos individualmente antes de descargarlos.
- Guarda los archivos en una subcarpeta con el nombre del usuario.
- Exporta informes en CSV o JSON.
- Guarda localmente la configuración y los usuarios recientes.

El escaneo y las descargas de imágenes y MP4 no requieren servicios externos.
La combinación HLS/DASH es opcional y requiere el asistente localhost de código
abierto y un permiso independiente. Los datos del escaneo no se suben a un
servidor del desarrollador. No incluye publicidad ni analítica.

Descarga únicamente contenido propio o autorizado. Esta extensión no está
afiliada ni respaldada por X Corp.
