# Chrome Web Store 本地化文案

以下文案用于商店后台的本地化 Store Listing。隐私政策、支持网址和权限披露在
所有语言中使用相同链接。

## English (`en`)

**Name:** Media Downloader for X

**Summary:** Scan media posts on X by username and date, preview the results,
and download selected images and videos.

**Description:**

Media Downloader for X is an unofficial Chrome extension that helps you scan,
review, and download visible images and videos from a specific X account. It is
designed for saving media you own or have permission to download.

HOW IT WORKS

1. Sign in to X and open a user page.
2. Open the extension from Chrome's persistent side panel. The username is
   detected automatically and can be edited if needed.
3. Choose an optional date range and maximum number of posts, then start the
   scan.
4. Review every discovered media item on a separate preview page.
5. Select the images and videos you want and download them to a folder named
   after the X username.

KEY FEATURES

- Persistent Chrome side panel that stays available while the target page opens.
- Automatic username detection from X user, media, and post pages.
- Recent username history for quick repeat scans.
- Optional start date, end date, and maximum post count controls.
- Detect multiple images and multiple videos attached to the same post.
- Highest-bitrate available MP4 selected separately for each video.
- Preview totals for all media, images, and videos.
- Filter preview results by image or video.
- View original image dimensions and video bitrate in the media information column.
- Select all, select none, or choose individual items before downloading.
- Save downloads under Downloads/<username>/ with organized filenames.
- Track the real completion state of each selected download and receive a final completion summary.
- Export the scan list as UTF-8 CSV or JSON.
- English, Simplified Chinese, Japanese, Korean, and Spanish interface support.

PRIVACY

Scanning and standard image/MP4 downloads are processed locally in your browser.
Settings, recent usernames, scan progress, and preview results are stored locally
using Chrome extension storage. No scan data is uploaded to a developer server.
The extension contains no ads, tracking, or analytics.

OPTIONAL HLS/DASH SUPPORT

Some videos are only available as HLS or DASH streams. Combining those streams is
an optional advanced feature that requires the open-source localhost helper with
FFmpeg and a separate localhost permission prompt. Images, standard MP4 videos,
and scanning do not require this helper.

IMPORTANT

The extension only processes media visible to your signed-in X session and does
not bypass login, privacy settings, access controls, or deleted content. Only
download content you own or are authorized to save, and follow applicable laws
and the source platform's terms.

Media Downloader for X is not affiliated with, endorsed by, or sponsored by X
Corp.

## 简体中文 (`zh_CN`)

**名称：** X 媒体下载器

**简短说明：** 按用户名和日期扫描 X 上的媒体帖子，预览结果并下载选中的图片
和视频。

**详细说明：**

X 媒体下载器是一款非官方扩展，用于整理和下载你拥有或获准保存的 X 媒体。

- 按日期和最大帖子数扫描用户媒体页。
- 在 Chrome 右侧边栏中操作，并从当前 X 页面自动识别用户名。
- 获取多图帖子的全部图片。
- 选择可用的最高质量 MP4 视频。
- 下载前在预览页逐项选择。
- 按图片或视频过滤，并在媒体信息列查看图片分辨率或视频码率。
- 将文件保存到以用户名命名的下载子目录。
- 导出 CSV 或 JSON 扫描报告。
- 在本地保存设置和最近使用的用户名。

扫描、图片和 MP4 下载不依赖外部服务。HLS/DASH 合并是可选功能，需要开源
localhost 辅助程序和单独授权。扫描数据不会上传到开发者服务器，不包含广告或
分析服务。

请仅下载你拥有或获准保存的内容。本扩展与 X Corp. 无关联，也未获得其认可。

## 日本語 (`ja`)

**名前：** X メディアダウンローダー

**概要：** ユーザー名と日付で X のメディア投稿をスキャンし、結果を確認して
選択した画像や動画をダウンロードします。

**説明：**

X メディアダウンローダーは、所有または保存許可のある X のメディアを整理・
ダウンロードするための非公式拡張機能です。

- 日付と最大投稿数を指定してユーザーのメディアページをスキャン。
- Chrome のサイドパネルで操作し、現在の X ページからユーザー名を自動検出。
- 複数画像の投稿からすべての画像を取得。
- 利用可能な最高品質の MP4 動画を選択。
- プレビューページで項目ごとに選択してダウンロード。
- 画像または動画で絞り込み、メディア情報列に画像解像度または動画ビットレートを表示。
- ユーザー名の付いたダウンロードサブフォルダーに保存。
- CSV または JSON のスキャンレポートを出力。
- 設定と最近のユーザー名をローカルに保存。

スキャン、画像、MP4 のダウンロードに外部サービスは不要です。HLS/DASH の
結合は任意機能で、オープンソースの localhost ヘルパーと個別の権限が必要です。
スキャンデータは開発者のサーバーへ送信されず、広告や分析も含まれません。

所有または保存許可のあるコンテンツのみダウンロードしてください。本拡張機能
は X Corp. と提携しておらず、同社の承認も受けていません。

소유하거나 저장 권한이 있는 콘텐츠만 다운로드하세요. 이 확장 프로그램은

## Español (`es`)

**Nombre:** Descargador multimedia para X

**Resumen:** Escanea publicaciones multimedia de X por usuario y fecha,
previsualiza los resultados y descarga imágenes y vídeos seleccionados.

**Descripción:**

Descargador multimedia para X es una extensión no oficial para organizar y
descargar contenido de X que te pertenece o que tienes permiso para guardar.

- Escanea la página multimedia de un usuario por fecha y cantidad máxima.
- Funciona en el panel lateral de Chrome y detecta el usuario de la página actual de X.
- Encuentra todas las imágenes de publicaciones con varias imágenes.
- Selecciona la mejor variante MP4 disponible.
- Permite elegir elementos individualmente antes de descargarlos.
- Filtra por imagen o vídeo y muestra dimensiones o tasa de bits en una sola columna de información.
- Guarda los archivos en una subcarpeta con el nombre del usuario.
- Exporta informes en CSV o JSON.
- Guarda localmente la configuración y los usuarios recientes.

El escaneo y las descargas de imágenes y MP4 no requieren servicios externos.
La combinación HLS/DASH es opcional y requiere el asistente localhost de código
abierto y un permiso independiente. Los datos del escaneo no se suben a un
servidor del desarrollador. No incluye publicidad ni analítica.

Descarga únicamente contenido propio o autorizado. Esta extensión no está
afiliada ni respaldada por X Corp.
